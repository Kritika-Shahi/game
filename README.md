# ShadowSwap Runner

A simple endless runner built with **Pygame** where the player can toggle between Light and Shadow modes. Collect yellow coins in Light mode, survive obstacles and monsters, and progress through levels.

## Controls
- **Space** – Jump (hold for a longer jump)
- **Shift** – Toggle Light/Shadow mode
- **R** – Restart after Game Over

## Features
- Dynamic speed increase over time
- Long‑jump mechanic based on key hold duration
- Health regeneration in Shadow mode
- Level progression with coin targets

## Running
```bash
python -m venv .venv
source .venv/bin/activate
pip install pygame
python main.py
```
